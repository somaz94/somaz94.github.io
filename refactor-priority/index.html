How the rank is computed

Each function is scored on four measurements taken from its own body — cyclomatic complexity (branch and loop keywords plus boolean operators), maximum nesting depth, line count, and parameter count. The score is the weighted sum, and every row names the measurement that drove it so a rank can be argued with.

Functions are located with brace matching or indentation, depending on the language, so a nested closure, a method on an object literal or a heavily macro-ed file can be split in the wrong place. Treat the output as a shortlist of candidates to open, not as a measurement.
