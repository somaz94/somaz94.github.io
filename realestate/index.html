2. 수치 및 표기 기준

가격지수: 특정 기준시점을 100으로 설정한 상대값이므로 실제 거래 금액이 아닙니다.

증감 표기: 금리와 지가변동률의 변동폭은 %p(퍼센트포인트)로, 지수 · 물량 · 금액의 변화율은 %(퍼센트)로 구분하여 표기합니다. (예: 금리가 3.93%에서 4.36%로 상승 시, 오해를 방지하고자 상대 변화율인 '+10.94%'가 아닌 '+0.43%p'로 표기)

4. 아파트 실거래가 데이터

국토교통부 공공데이터포털(data.go.kr) 오픈 API를 통해 수집됩니다. API 점검, 승인 지연 또는 데이터 미활성화 기간에는 서비스 신뢰성을 위해 해당 데이터 표가 일시적으로 비노출 처리될 수 있습니다.

면적: 거래 목록의 면적은 공급면적 기준 평형과 그 아래 공급/전용 ㎡로 적었습니다(예: 36평형, 119/84㎡). ㎡는 소수점 아래를 버리고 평형은 반올림했습니다. 실거래 자료에는 전용면적만 있어서, 공급면적은 건축물대장의 전유면적에 주건축물 공용면적을 더해 따로 구했습니다. 그래서 분양 공고의 공급면적과 1~2㎡ 다를 수 있고, 대장에서 찾지 못한 단지는 전용면적만 적었습니다. 평당가는 모두 전용면적 기준입니다.

지표는 한국은행 ECOS에서 평일 하루 두 번 받아와 빌드 시점에 이 페이지에 새겨 넣습니다 — 읽는 동안에는 아무것도 요청하지 않습니다. 계산기는 모두 브라우저 안에서만 동작하며, 입력한 금액은 저장되지도 전송되지도 않습니다. 계산 결과는 참고용 추정치입니다. 세율과 규제는 수시로 바뀌므로 실제 신고 · 대출 · 계약 전에는 반드시 관할 기관과 금융기관에 확인하시기 바랍니다.
